01 · Selected work

Work that runs in production

  1. LLMProduction

    RAG and agent platform

    Retrieval-augmented generation on PostgreSQL and pgvector, with multi-provider LLM routing, embeddings, tool orchestration and agent workflows.

    Runs in production inside a multi-tenant SaaS product.

  2. InfraPostgreSQL

    Postgres-native task executor

    Distributed task execution built entirely on PostgreSQL: queuing, fan-out and join, and idempotency.

    No Celery, no Redis. Fewer moving parts to run.

  3. PerformanceSQL

    Analytics query, 239 s → 0.9 s

    Rollup tables, a deliberate indexing strategy, JSONB and full-text search.

    Over 250× faster.

  4. PerformanceORM

    ORM query elimination

    Found and removed N+1 patterns across hot request paths.

    Queries per request from 500+ to about 5–10. SQL time from ~20 s to ~1–2 s.
